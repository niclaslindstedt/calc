# Examples

Sample documents in the app's storage format (see
[`docs/storage-format.md`](../docs/storage-format.md)).

- [`groceries-budget-1b2c3d.md`](groceries-budget-1b2c3d.md) — a saved
  session with a title, a folder, and a commented tape entry. Drop it into a
  connected storage folder under `calculations/` and it appears in the
  sidebar.
- [`folders.json`](folders.json) — the folder registry that names the
  `f-shopping` folder the session above references.
